# Project Repository

This is the initial README file for the project.

## Music Library Backend API

This Express.js backend provides:
- User registration, login, password update
- Music upload, retrieval, search/filter
- Playlist CRUD (create, update, delete), add/remove tracks
- Audio streaming endpoints
- Account settings

Requires database connection via the following environment variables:
- DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME, JWT_SECRET

For API documentation, visit `/docs` route when the backend is running.
